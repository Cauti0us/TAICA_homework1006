主題：用 Vibe Coding 做出一個互動網頁

作業說明：

請發想一個你自己覺得有趣、想做的 Web App，並利用 AI 協助你從想法一路完成可以實際操作的網頁。

這次不要求你自己從頭寫程式，重點是學習如何：

把自己的想法說清楚 → 和 AI 討論出規格 → 利用 Vibe Coding 實作 → 將作品公開在 GitHub Pages。

-----------------------------------------------------------------------------------------------

步驟一：和 AI 討論你的想法，整理出一份「規格書」。

步驟二：根據規格書，利用 Vibe Coding 完成網頁。

最後請整理成單一 index.html 檔案
CSS、JavaScript 可以直接寫在 HTML 裡
網頁需要可以實際開啟、操作
步驟三：將作品上傳到 GitHub，並使用 GitHub Pages 公開網站。

-----------------------------------------------------------------------------------------------

繳交期限：10/19 23:59 （遲交期限：10月20日 16:00）

繳交標題格式：學校 學號 系級 姓名 主題 (主題可打可不打) (學校、系級打簡稱即可)

繳交內容形式：請直接在「文字輸入」區進行繳交。（不需要另外製作 PDF 或上傳附件。）

內容必須包含：網站連結、網站介面截圖、規格文字說明

-----------------------------------------------------------------------------------------------

評分標準：

0 分： 未作答，或幾乎沒有可辨識的作業內容。

1 分： 與本週作業主題無關，或誤貼其他週作業。

2 分： 只有截圖沒有連結（或連結打不開）

3～4 分： 有完成基本網頁並上傳 GitHub，但無規格書內容。

5～6 分： 有完成基本網頁並上傳 GitHub，但規格書較簡略，或部分功能無法正常操作。

7～8 分： 有完整的規格書、可正常操作的 index.html，並成功透過 GitHub Pages 公開作品；實作內容大致符合原本規格。

9～10 分： 完整達成以上要求，且：

規格書清楚、具體。
網頁具有實際的互動功能，而不只是靜態文字。
實際作品與規格書有良好對應。
